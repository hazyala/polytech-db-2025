# Oracle SQL과 한빛마트 DB 설계

고객·제품·주문 SQL 실습과 온라인몰의 요구 분석 → 개념 설계 → 논리 설계 → 테이블 설계 산출물을 모았다.

## 설계한 데이터

[1117.sql](1117.sql)은 `한빛마트제조`, `한빛마트회원`, `한빛마트상품`, `한빛마트게시글`, `한빛마트주문`을 생성한다. 상품은 제조업체를 참조하고, 게시글은 작성 회원을, 주문은 회원과 상품을 참조한다. 상품 재고·단가·공급량에 음수 방지 CHECK 제약을 두었다.

drawio XML과 PNG에는 요구 분석 및 개념·논리·테이블 설계가 있다. XML은 diagrams.net에서 열어 관계와 속성을 확인한다. SQL은 Oracle 환경에서 실행하며 `1117.sql`의 시작 부분은 같은 이름의 테이블을 삭제하므로 별도 실습 schema를 사용한다.

## 날짜별 실습

- [0825.sql](0825.sql): 고객·제품·주문·배송업체 테이블과 예제 데이터. JDBC 고객 관리 과제가 사용하는 고객·주문·제품 schema다.
- `0901.sql`~`0922.sql`: 날짜별 조회 SQL 실습.
- [0929.sql](0929.sql): 추가 테이블과 우수고객·업체별제품수·제품2 view.
- [1117.sql](1117.sql): 한빛마트 온라인몰 테이블 설계.

한빛마트 테이블과 JDBC 과제의 `고객`·`주문`·`제품` 테이블은 이름과 구조가 다르다. Java 실행은 [고객 관리 README](../DataBase_Midterm-Exam_1109/README.md)를 따른다.
